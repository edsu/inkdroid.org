A few days ago I wrote about a new tool called [wacz-pdf], which will read a WACZ file and write out each web page as a PDF file.

I got some quick feedback from [Henry Wilkinson] who suggested that it could be useful to allow a user to extract a [Markdown] file instead of a PDF. He also pointed out that the [defuddle] JavaScript library could be useful for doing it. defuddle is open source, and is part of the browser extension that [Obsidian] uses to save things from the web.

Claude chewed on this idea for a bit. I happened to notice at some point that it decided to extract the HTML from the WARC and feed that to defuddle. That worked fine, but it wouldn't work for all the web pages that are dynamically assembled with JavaScript.

Since I didn't have any WACZs nearby that had dynamic pages in them Claude decided there really weren't many WACZs that contained pages like this. Even when I challenged that there were, Claude still opted to use replay as a fallback when absolutely necessary. Oh Claude, you're so funny.

In the end I did manage to redirect Claude at focusing on using the HTML from the replayed page DOM instead of the HTML in the WARC. The code simply waits for the page to settle, after any optional click behaviors are applied. It then uses Playwright to inject some JavaScript into the replayed page, which serializes the DOM as HTML, and passes it back out to the calling program, which then gives it to defuddle.

These changes did kinda require a change in name since wacz-pdf didn't adequately describe this Markdown extraction functionality. So, the tool is now called [waczdoc], which has three subcommands `pdf`, `markdown` and `list`:

```shell
waczdoc markdown reallife.wacz --output markdown
```

I wanted to choose the awkward name waczdoc (despite Claude telling me it was
a terrible name) because the cool thing about extracting to Markdown is it
opens up all kinds of possibilities to transform to other things via [Pandoc],
if the mood should take you. Maybe Claude was right about the name being
awkward, but I like it :)
