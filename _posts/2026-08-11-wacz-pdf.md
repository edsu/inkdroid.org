I was recently working with a journalist who wanted the articles they had
written archived from the newspaper's website. I gave them a [WACZ] file (created with [Browsertrix]), and they were like:

> Hey nice! But could I get the articles as PDFs?

A WACZ is a good container for a web crawl. It plays back easily in open-source
replay software like Browsertrix and ReplayWebPage. But it's not always the
most convenient format for a non-archivist who wants to read, annotate, print or file
away a set of their articles.

I've been trying to put my Claude access to work while it lasts. So I worked
with Claude to write a small CLI utility, [wacz-pdf], that extracts all (or
a subset) of the pages from a WACZ and writes them out as PDF files, one per
page.

The pages come from the crawler's own page list (`pages/pages.jsonl`), falling
back to the CDX index for archives that don't have one. Each page is then
handled according to what it is. HTML gets replayed through [wabac.js],
Webrecorder's own replay engine, running as a service worker inside headless
Chromium, so the CSS, images and fonts are all served from the archive and the
page renders the way it was captured. Then it's printed with Playwright's
`page.pdf()`.

Archived PDFs are simply copied out of the WARC verbatim: an
archived PDF is already a PDF, and replaying one would just screenshot
Chromium's PDF viewer. Copying the original bytes keeps the text layer, fonts
and vectors intact, and doesn't need a browser at all. That second path could be a non-niche case, if you are (for example) working with a government site that hosts lots of PDFs.

One feature that was born out of necessity was the ability to run a bit of
custom JavaScript on each page before it is printed. On this particular site
a modal occasionally appeared over the page asking people to subscribe, and it
obscured a significant portion of the article. The content was still there in
the DOM, the overlay was just painted on top of it. So the fix was a teensy bit
of JavaScript to remove the modal and unlock scrolling, handed to `wacz-pdf`
with `--inject` as part of the run.

wacz-pdf is on NPM so if you have [NodeJS] you can try it with:

```
$ npx playwright install chromium
$ npx wacz-pdf archive.wacz --list
$ npx wacz-pdf archive.wacz -o pdfs
```
